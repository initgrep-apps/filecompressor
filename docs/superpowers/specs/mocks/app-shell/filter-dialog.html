What changed + component map

  • Sort: two items only, Newest first / Oldest first, single-select ToggleGroup.
  • Since: shadcn Date Picker — Popover + Calendar, with a preset column (All time, Today, Last 7 days, Last 30 days, This month, Last 3 months) and a custom date. The trigger shows the resolved label.
  • Category: the same four glyphs as the staging area (CATEGORY_GLYPHS from DropZone.tsx) and the same category tones (blue image, violet video, red PDF, amber document). Extract to a shared CategoryIcon; no duplicated SVGs.
  • Controls: Dialog, ToggleGroup, Popover, Calendar, Badge, Button. No checkboxes.
  • Apply/Cancel: staged draft; Apply commits and refetches; Cancel discards; Clear all resets the draft.
