Compress flow — redesigned mockups (v2)

Changes from v1 per your feedback: History badge removed, Show Finished removed (rows always expanded — no collapse/expand controls), header is now Batch #12 [status pill] with the pill transitioning Compressing → Complete, exit button renamed New batch, and the app always launches on staging.

  1. Screen 1 · Staging — drop/browse hero, staged table, unsupported rows dimmed, footer counts + Compress. App always starts here.
  2. Screen 2 · Batch running — locked screen, dynamic kanban lanes, rows ordered compressing → completed → queued.
  3. Screen 3 · Batch complete — status pill flips to Complete, New batch appears, all rows expanded (nothing collapsed).

Jump: Screen 1 · Screen 2 · Screen 3

Screen 1Staging — drop & review

The app opens here on every launch. The only screen with a drop zone. Unsupported rows are dimmed and excluded from the Compress count.

Screen 2Batch running — kanban monitor

Header is Batch #12 + a live status pill (pulsing green dot). Locked: no drop zone, no back. One lane per category present in the batch; single-type batch = one lane, left-aligned. Lane rows ordered compressing → completed → queued, nothing ever collapses. Strategy notes appear on completed rows only.

Screen 3Batch complete — results & exit

Status pill flips to Complete and New batch appears. All rows stay expanded — no collapse, no Show Finished. Same screen (with a "Batch cancelled" toast) if the user hits Cancel All: cancelled rows sit in the completed section as muted "Cancelled", queued rows stay pending.
